# Public listing sources (27 Nov 2026)

How the O19 import reads each source. None offers a documented API; each reader calls the same public endpoint the source's own web page uses, with no sign-in. Saved answers for tests are in `supabase/functions/import-public-listings/fixtures/`.

- **NeST tenders:** `POST https://nest.go.tz/gateway/nest-app/graphql`, operation `getPublishedEntityViewData` with `entityStatus IN PUBLISHED`, paged (209 open tenders on 27 Nov). A procuring body's region and district come from `POST https://nest.go.tz/gateway/nest-uaa/graphql`, `getProcuringEntityDetailsByUuid`. A tender has no address of its own (`/tender-details` keeps it in page state), so listings link to `https://nest.go.tz/tenders/published-tenders` and carry the tender number. Fees and bid security sit in the tender documents, which need a NeST login, so tenders get the "Fees or bid security may apply" note.
- **Ajira:** `POST https://portal.ajira.go.tz/candidates/graphql`, query `getVacancies` (only 5 vacancies, 3 open, on 27 Nov). Most public-service adverts are PDF notices on www.ajira.go.tz, which the import does not read.
- **CRDB Bank:** `GET https://careers.crdbbank.co.tz/api/v1/requisitions/job-posts/open?pageNumber=0&pageSize=100&status=INTERVIEW` (9 open jobs on 27 Nov). The bank's own careers page links there.
- **Ajira adverts (PDF):** `GET https://www.ajira.go.tz/api/v1/archive?page=1&limit=20&category=vacancies` lists notices with a `download_token`; the PDF is `GET https://www.ajira.go.tz/api/v1/vacancies/attachment/token/<token>/download`. Of three checked on 28 Nov, two had real text (5 and 9 pages) and one was a scanned image (13 pages, no text), so they are read by Gemini, which handles both.
- **Gemini (free tier), chosen 28 Nov over Azure Translator and the Claude API:** secret `GEMINI_API_KEY` (optional `GEMINI_MODEL`, default `gemini-3.1-flash-lite`; `gemini-2.5-flash` is closed to new keys and the larger Flash models often answered "high demand" on 28 Nov), from aistudio.google.com, set as a Supabase function secret only. On the free tier Google may use what is sent to improve its products, so only public listing text and public advert PDFs go to it, never member data. Free daily limits for the model were not confirmed. Not set up yet.
- A first local run took under two minutes and saved 218 listings; a second run saved nothing new.
- **Timing (28 Nov, local):** one cron call per source, five minutes apart, each under the Edge Function wall-clock limit (believed about 150 s on the free plan, not confirmed). A first NeST run with every tender new took 68 s (region lookups 10 at a time); with up to 60 Gemini translations a run, about 100 s. Ajira adverts: about 8 s per PDF, 4 PDFs a run. The real key read a 13-page scanned DART advert into 10 posts and a text advert into 1, with translations. Gemini's free tier refused some translation batches during a 220-listing run; untranslated listings are retried on later runs.
