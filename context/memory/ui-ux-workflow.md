# Kingdom Connect UI and UX workflow

- Work on one agreed screen or part of a flow at a time. Run it locally, share the preview and checks, then wait for the user's review before moving on.
- Use Apple’s Human Interface Guidelines as a design reference for readable typography, generous spacing, clear hierarchy, and restrained motion that respects reduced-motion preferences.
- Preserve Kingdom Connect’s burgundy-and-gold identity, existing brand imagery where appropriate, and the full meaning of its English and Kiswahili copy. Keep the interface emoji-free.
- Build responsive layouts with semantic HTML and accessible web controls. Check small phones and desktop, keyboard focus, language switching, and unnecessary scrolling.
- Leave changes uncommitted unless the user asks for a commit.
